دسترسی برنامه‌ای به داده

تقویم شهدا در گام «Data First» است: داده از رابط کاربری جدا شده و در قالب دو لایه JavaScript منتشر می‌شود. اپلیکیشن‌ها و محصولات اکوسیستم می‌توانند همین داده را مصرف کنند.

نسخه فعلی یک API ایستا است: فایل‌های JavaScript با اسکریپت قابل بارگذاری‌اند. نسخه سروری (REST) در نقشه راه مرحله چهارم سند مادر تعریف شده است.
