# تقویم شهدا

تقویم شهدا یک سایت و محصول **مستقل** است. این پوشه باید بدون وابستگی به ساختار فایل‌های شهیدپورتال یا بانک جامع شهدا قابل انتقال و میزبانی باشد.

## ساختار مستقل
- `index.html` صفحه اصلی
- `assets/css/calendar.css` سبک و ظاهر
- `assets/js/calendar.js` منطق رابط و تقویم
- `assets/fonts/` فونت‌های محلی
- `assets/images/` تصاویر و لوگوی محلی

## ارتباط با اکوسیستم
ارتباط با محصولات دیگر فقط از طریق پیوندهای بیرونی و ظریف در فوتر انجام می‌شود:
- بانک جامع شهدا
- شهیدپورتال

این سایت برای اجرا به هیچ فایل، فونت، تصویر، CSS یا JavaScript خارج از این پوشه نیاز ندارد.

## وضعیت فعلی توسعه
- موتور نمایش تقویم هجری شمسی با تکیه بر تقویم Persian در مرورگر و پشتیبانی از سال‌های ۱۳۰۰ به بعد
- نمایش واقعی ماه، هفته و سال
- انتخاب روز و نمایش جزئیات همان روز
- جست‌وجوی رویداد بر اساس متن، نوع رویداد و تاریخ شمسی
- ساختار داده‌ای اولیه برای رویدادها با تاریخ، نوع، عنوان، توضیح و برچسب
- آماده‌سازی رابط برای اتصال بعدی به بانک جامع رویدادها و پرونده‌های شهدا

## توسعه بعدی
بانک کامل رویدادها، اتصال رویدادها به شناسه شهید، عملیات، مکان، یگان، روایت، سند و تصویر و سپس API مستقل تقویم در مراحل بعد اضافه خواهد شد.
