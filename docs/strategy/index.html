مرکز راهبری و راهبردی شهیدپورتال

فضای پایه برای تعریف، برنامه‌ریزی، اولویت‌بندی و پیاده‌سازی طرح‌های جدید

از این صفحه، طرح‌های آینده به‌صورت منسجم تعریف و سپس به پروژه، زیرسامانه یا قابلیت اجرایی تبدیل می‌شوند.

شروع برنامه‌ریزی جدید

این صفحه عمداً ساده نگه داشته شده است. هر ایده یا طرح جدید ابتدا اینجا تعریف می‌شود؛ سپس جایگاه آن در معماری مادر، سبد پروژه‌ها، داده، فناوری، راهبری و نقشه راه مشخص خواهد شد.

قاعده شروع: ابتدا مسئله و هدف را مشخص می‌کنیم؛ بعد تصمیم می‌گیریم که راه‌حل باید «پروژه»، «زیرسامانه»، «خدمت»، «قابلیت مشترک»، «داده‌محصول» یا «اصلاح فرایند» باشد.

مسیرهای اصلی

معماری مادرساختار کلان، لایه‌ها و ارتباط بخش‌ها سبد پروژه‌هاتعریف، اولویت، مالک و وضعیت طرح‌ها نوآوری و توسعهایده تا نمونه، پایلوت و محصول سیاست‌گذاری و رصدخانهمسئله، شواهد، تحلیل و پایش اکوسیستم داده و استانداردشناسه، داده، اعتبار، API و استانداردها نقشه راه اجرااولویت‌بندی و تبدیل طرح به مراحل عملیاتی طرح جدیدفرم پایه برای تعریف هر طرح تازه

قاعده یکپارچگی صفحات

تمام صفحات جدید این بخش از همین منوی کناری، هویت بصری، مسیر بازگشت و ساختار ناوبری استفاده می‌کنند تا مرکز راهبری به‌صورت یک فضای واحد و منسجم توسعه پیدا کند.
