# تقویم شهدا

تقویم شهدا یک سایت و محصول **مستقل** است. این پوشه بدون وابستگی به ساختار فایل‌های
شهیدپورتال یا بانک جامع شهدا قابل انتقال و میزبانی است.

## وضعیت جاری (به‌روزرسانی 2026-10-05)

این پوشه با نسخه کامل محصول همگام شده است: پوسته گرافیکی مشترک (هدر، منو، فوتر)،
لایه داده واقعی و ۲۲ صفحه.

### لایه داده
- `assets/js/site-data.js` — داده واقعی: اشخاص، رویدادها، مکان‌ها، دوره‌ها و منابع؛
  همراه شناسه پایدار، منبع و وضعیت اعتبار هر رکورد.
- `assets/js/page-data.js` — آداپتور: همان داده در شکلی که صفحات فهرست و جست‌وجو
  مصرف می‌کنند. این فایل تولیدشده است؛ برای تغییر داده `site-data.js` را ویرایش کنید.
- `assets/js/site.js` — پوسته: منوی موبایل و وضعیت صفحه فعال.

### صفحات
خانه (`index.html`)، تقویم، امروز، روز (`day.html`)، شهدا، پرونده شهید، رویدادها،
پرونده رویداد، مکان‌ها، پرونده مکان، دوره‌ها، پرونده دوره، منابع، پرونده منبع،
جست‌وجو، دانشنامه (`encyclopedia.html`)، همکاری، درباره، تماس، ۴۰۴ و
مستندات داده (`api.html`).

### PWA
`manifest.json` و آیکون‌های ۱۹۲ و ۵۱۲ پیکسل.

### اجرای محلی
سایت بدون سرور و بدون build کار می‌کند؛ کافی است `index.html` را باز کنید.

## ارتباط با اکوسیستم
ارتباط با محصولات دیگر فقط از طریق پیوندهای بیرونی و ظریف در فوتر انجام می‌شود:
- بانک جامع شهدا
- شهیدپورتال

این سایت برای اجرا به هیچ فایل، فونت، تصویر، CSS یا JavaScript خارج از این پوشه نیاز ندارد.

## سابقه

- موتور نمایش تقویم هجری شمسی با تکیه بر تقویم Persian در مرورگر و پشتیبانی از سال‌های ۱۳۰۰ به بعد
- نمایش واقعی ماه، هفته و سال
- انتخاب روز و نمایش جزئیات همان روز
- جست‌وجوی رویداد بر اساس متن، نوع رویداد و تاریخ شمسی
- ساختار داده‌ای اولیه برای رویدادها با تاریخ، نوع، عنوان، توضیح و برچسب
- آماده‌سازی رابط برای اتصال بعدی به بانک جامع رویدادها و پرونده‌های شهدا

## توسعه بعدی
بانک کامل رویدادها، اتصال رویدادها به شناسه شهید، عملیات، مکان، یگان، روایت، سند و تصویر و سپس API مستقل تقویم در مراحل بعد اضافه خواهد شد.
