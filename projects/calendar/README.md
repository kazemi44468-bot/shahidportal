# تقویم شهدا

تقویم شهدا یک سایت و محصول **مستقل** است. این پوشه باید بدون وابستگی به ساختار فایل‌های شهیدپورتال یا بانک جامع شهدا قابل انتقال و میزبانی باشد.

## ساختار مستقل
- `index.html` صفحه اصلی
- `assets/css/calendar.css` سبک و ظاهر
- `assets/js/calendar.js` منطق رابط و تقویم
- `assets/fonts/` فونت‌های محلی
- `assets/images/` تصاویر و لوگوی محلی

## ارتباط با اکوسیستم
ارتباط با محصولات دیگر فقط از طریق پیوندهای بیرونی و ظریف در فوتر انجام می‌شود:
- بانک جامع شهدا
- شهیدپورتال

این سایت برای اجرا به هیچ فایل، فونت، تصویر، CSS یا JavaScript خارج از این پوشه نیاز ندارد.

## توسعه بعدی
موتور دقیق تقویم هجری شمسی، بانک رویدادها، جست‌وجوی واقعی و اتصال داده‌ای به پرونده شهدا، عملیات، مکان‌ها، روایت‌ها و اسناد در مراحل بعد اضافه خواهد شد.
