# شهیدپورتال | ShahidPortal

**پورتال جامع خدمات، جامعه، دانش و میراث شهدا و ایثارگران**

این مخزن محل طراحی و توسعه مرحله‌به‌مرحله پروژه شهیدپورتال است.

## ایده مرکزی

شهیدپورتال قرار نیست یک خبرگزاری، سایت یادبود یا نسخه دیگری از سامانه‌های موجود باشد. مأموریت آن ایجاد یک لایه یکپارچه برای دسترسی، کشف، ارتباط، هدایت، هماهنگی و راهبری خدمات، اطلاعات، مراکز، خانواده‌ها، تشکل‌ها، منابع فرهنگی، پژوهش‌ها، آرشیوها و ظرفیت‌های حوزه شهدا و ایثارگران است.

## پنج مفهوم بنیادین

- خدمت: دسترسی ساده و یکپارچه به خدمات و ارجاع به ارائه‌دهنده مناسب
- زندگی: سلامت، خانواده، مسکن، اشتغال، آموزش و اقتصاد
- جامعه: خانواده‌ها، ایثارگران، سازمان‌ها، تشکل‌ها، خیرین و داوطلبان
- یاد: شهدا، روایت‌ها، مزارها، یادمان‌ها و میراث
- دانش: دانشنامه، پژوهش، کتابخانه، اسناد و تاریخ شفاهی
