# تقویم شهدا — پروژه شهیدپورتال

**تقویم شهدا** یکی از محصولات مستقل اکوسیستم شهیدپورتال و از پروژه‌های تخصصی مرتبط با **بانک جامع شهدا** است.

## جایگاه محصول
این پروژه مستقل طراحی و توسعه می‌شود، اما سه ارتباط اصلی آن حفظ خواهد شد:
- **ارتباط هویتی:** استفاده از هویت و خانواده بصری مشترک اکوسیستم شهیدپورتال.
- **ارتباط راهبری:** توسعه محصول در چارچوب و جهت‌گیری کلان شهیدپورتال.
- **ارتباط محتوایی:** اتصال رویدادهای زمانی به پرونده شهدا، عملیات‌ها، مکان‌ها، روایت‌ها، اسناد، گنجینه و سایر محصولات تخصصی.

اصل کلی: **مستقل در تجربه و محصول، متصل در محتوا و اکوسیستم.**

## هدف
تقویم شهدا یک تقویم تخصصی برای کشف و نمایش:
- سالروز شهادت و تولد شهدا
- عملیات‌ها و وقایع دفاع مقدس
- مناسبت‌های ملی، مذهبی، دفاع مقدس و فرهنگی
- یادواره‌ها و مراسم
- روایت، تصویر، سند، وصیت‌نامه و رسانه مرتبط با هر روز
- آرشیو تاریخی و جست‌وجوی رویدادها

## ارتباط با سایر محصولات
**بانک جامع شهدا** مرجع اصلی پرونده و هویت شهداست.  
**تقویم شهدا** لایه زمانی و رویدادمحور است و مشخص می‌کند «در چه روزی چه چیزی رخ داده یا چه چیزی را باید به یاد آورد».  
**شهیدپورتال** بستر مادر برای ارتباط این محصول با دانشنامه، روایت، گنجینه، اطلس، رسانه و سایر پروژه‌هاست.

## مسیر توسعه
نسخه فعلی نمونه اولیه رابط و سناریوی محصول است. در مرحله بعد:
1. موتور دقیق تقویم هجری شمسی پیاده‌سازی می‌شود.
2. مدل داده رویدادها تعریف می‌شود.
3. رویدادها به شناسه‌های شهدا و موجودیت‌های بانک جامع شهدا متصل می‌شوند.
4. پیوند عملیات، شهر، یگان، مکان، سند، تصویر و روایت اضافه می‌شود.
5. API و خدمات قابل استفاده برای سایر محصولات توسعه می‌یابد.
